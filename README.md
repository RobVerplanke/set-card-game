# SET Card Game

A learning project — a digital implementation of the classic SET card game.

## About

SET is a pattern recognition card game created by Marsha Falco in 1974.
The deck consists of 81 unique cards, each defined by four features:
number, color, shape, and shading.

Players race to find "sets" of three cards where each feature is either
all the same or all different across the three cards.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
